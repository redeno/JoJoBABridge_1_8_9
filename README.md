# Chat Bridge Mod для Minecraft 1.8.9

Мод для создания отдельного канала общения между игроками, у которых установлен этот мод.

## 🎯 Возможности

- **Команда `/bridge`** - Открывает GUI меню для включения/выключения чат бриджа
- **Команда `/bc <сообщение>`** - Отправляет сообщение в бридж чат
- **Автоматическое скрытие** - Игроки без мода не видят сообщения бриджа
- **Сохранение настроек** - Конфигурация сохраняется между сессиями
- **Клиентский мод** - Работает на любых серверах, не требует установки на сервер

## 🚀 Быстрая сборка

### Если у вас Gradle 8+ (современные версии):
```bash
./fix-gradle.sh
```
Затем используйте созданный wrapper:
```bash
./gradlew setupDecompWorkspace
./gradlew build
```

### Если у вас старая версия Gradle или Java 8:
```bash
./build-mod.sh
```

Готовый мод будет в `build/libs/chatbridge-1.0.0.jar`

## 🎮 Использование

1. Установите Minecraft Forge 1.8.9
2. Поместите `chatbridge-1.0.0.jar` в папку `mods`
3. В игре используйте:
   - `/bridge` - настройки
   - `/bc Привет!` - отправить сообщение

## ⚙️ Требования

- Minecraft 1.8.9
- Minecraft Forge 1.8.9-11.15.1.2318-1.8.9
