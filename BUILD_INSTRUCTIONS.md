# Chat Bridge Mod - Инструкции по сборке

## Требования

- Java 8 (JDK 1.8)
- Minecraft 1.8.9
- Minecraft Forge 1.8.9-11.15.1.2318-1.8.9

## Сборка мода

1. **Клонирование репозитория:**
   ```bash
   git clone <repository-url>
   cd chatbridge-mod
   ```

2. **Сборка мода:**
   ```bash
   ./gradlew build
   ```
   
   Или на Windows:
   ```cmd
   gradlew.bat build
   ```

3. **Готовый мод будет находиться в:**
   ```
   build/libs/chatbridge-1.0.0.jar
   ```

## Установка

1. Установите Minecraft Forge 1.8.9
2. Скопируйте `chatbridge-1.0.0.jar` в папку `mods` вашего Minecraft
3. Запустите Minecraft с профилем Forge

## Использование

### Команды:
- `/bridge` - Открыть меню настроек чат бриджа
- `/bc <сообщение>` - Отправить сообщение в бридж чат

### Функции:
- **Бридж чат**: Игроки с установленным модом могут общаться в отдельном канале
- **Переключатель**: В GUI меню можно включить/выключить бридж чат
- **Автоматическое скрытие**: Сообщения бриджа скрываются, если функция выключена
- **Цветовое кодирование**: Сообщения бриджа имеют особое форматирование

### Конфигурация:
Настройки сохраняются в файле `config/chatbridge.cfg`

## Разработка

### Настройка среды разработки:
```bash
./gradlew setupDecompWorkspace
./gradlew idea  # для IntelliJ IDEA
# или
./gradlew eclipse  # для Eclipse
```

### Запуск в среде разработки:
```bash
./gradlew runClient
```

## Особенности

- **Клиентский мод**: Работает только на клиенте, не требует установки на сервер
- **Совместимость**: Совместим с ванильными серверами
- **Безопасность**: Не влияет на игровой процесс игроков без мода
- **Производительность**: Минимальное влияние на производительность
